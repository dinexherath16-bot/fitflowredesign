# FitFlow Redesign

## Project Overview

FitFlow is a fitness application redesign project developed for the IT3060 – Human Computer Interaction module.

The project focuses on designing a scalable, secure and cross-platform fitness application that supports Android, iOS and web platforms.

## Objectives

The main objectives of the FitFlow redesign are:

* Provide a consistent cross-platform user experience.
* Support workout and nutrition tracking.
* Provide personalized fitness recommendations.
* Support real-time features.
* Protect user and health-related data.
* Provide a scalable and maintainable architecture.

## Technology Stack

| Component      | Technology           |
| -------------- | -------------------- |
| Frontend       | Flutter              |
| Backend        | Node.js + NestJS     |
| Database       | PostgreSQL           |
| Authentication | Supabase Auth        |
| AI/ML Service  | Python + FastAPI     |
| Caching        | Redis                |
| Real-Time      | WebSockets           |
| Storage        | Cloud/Object Storage |

## Recommended Architecture

The proposed architecture uses:

**Flutter → NestJS → PostgreSQL**

with:

**Supabase Auth + FastAPI AI/ML + Redis + WebSockets**

The architecture separates frontend, backend, database, authentication, caching and AI/ML responsibilities.
